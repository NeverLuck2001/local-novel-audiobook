## Remaining limits

The new UI has not run an entire-novel endurance benchmark, and no new GPU synthesis is launched alongside the protected external task. Base-clone audio validation was added in 0.3.0; see the current handoff above for its scope. Pausing waits for the currently running inference/FFmpeg operation. ETA is approximate and needs current-run synthesis data. Pronunciation mappings operate within segments and may miss a phrase split across a hard boundary. Strong pitch/rate changes can reduce naturalness. The launcher/file-picker target is Windows; Linux/WSL needs its own validation.
